# 스텔 다시보기 찾기

스텔라이브 멤버가 **어떤 게임을 한 방송인지** 검색해서 치지직·유튜브 다시보기로 바로 가는 비공식 팬사이트예요.

👉 **https://stelvodsearch.sbk-dev.com**

## 이런 걸 할 수 있어요

- 게임 이름이나 줄임말로 검색 (마크, 발로, 롤…)
- 멤버 · 플랫폼(치지직/유튜브) · 연도로 거르기, 최신순/오래된순 정렬
- 같은 날 올라온 치지직 다시보기와 유튜브 다시보기를 한 방송으로 묶어서 보여줘요
- 한 방송에서 여러 게임을 했으면 그 구간을 노란색으로 표시하고, 유튜브는 그 시간으로 바로 이동해요
- 검색한 상태가 주소에 남아서 링크로 그대로 공유할 수 있어요

## 정보는 어디서 오나요

- **치지직**: 멤버 채널의 공개 다시보기 목록 (제목, 카테고리, 날짜, 길이)
- **유튜브**: 멤버별 다시보기 채널 (YouTube Data API)
- 6시간마다 새 다시보기를 자동으로 가져오고, 일주일에 한 번 전체를 다시 확인해서 지워진 영상을 정리해요
- 영상이나 썸네일은 저장하지 않아요. 목록 정보만 모아서 **원본 다시보기로 연결**해요

## 지키는 것

- 비공식 · 비상업 팬사이트예요. 스텔라이브, 치지직, YouTube와 관계없어요
- 광고 없음, 방문자 추적 · 분석 없음
- 스텔라이브 공식 로고나 이미지를 쓰지 않아요
- 연령 제한 · 블라인드 · 유료(구독자 전용) 다시보기는 넣지 않아요

## 문의 · 삭제 요청

잘못된 정보나 내려야 할 내용이 있으면 [Issues](https://github.com/pst10101/stel-vod-finder/issues)에 남겨주세요. 확인하는 대로 바로 반영할게요.

## 코드

```

data/      수집된 목록 (자동 갱신)
```
